# Домашнее задание к работе 6
## Условие задачи
Составить программу, которая проверяет принадлежит ли заданная пользователем точка с координатами (х, у) заданным закрашенным (заштрихованным) областям, показанным на рисунках в табл., и выводит на экран сообщение.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Ввести точку:
   - `x` — координата точки по оси X.
   - `y` — координата точки по оси Y.
3. Проверить точку на принадлежность заштрихованной области:
   - `x`$^2$ + `y`$^2$ <= 2
   - `y` <= -`x`
   - `x` >= 0
4. Вывести результат проверки.
5. **Конец**

## 2. Реализация программы

```C
#include <stdio.h>
#include <locale.h>
#include <math.h>

int main()
{
    setlocale(LC_CTYPE, "RUS.UTF-8");

    float x, y;
    puts("Введите координаты точки через пробел: ");
    scanf("%f %f", &x, &y);

    if (x*x + y*y <= 2 && y <= -x && x >= 0)
        printf("Точка (%f, %f) принадлежит заштрихованной области", x, y);
    else
        printf("Точка (%f, %f) не принадлежит заштрихованной области", x, y);

    return 0;
}
```
